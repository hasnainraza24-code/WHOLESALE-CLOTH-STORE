# Raza Wholesale Cloths

A full-stack wholesale clothing e-commerce web application built to provide a simple, modern and convenient shopping experience for wholesale clothing customers.

## 🚀 Features

- User Registration & Login
- Dynamic Login / Profile Navigation
- Product Listing
- Product Details
- Product Quantity Selection
- Add to Cart
- Buy Now
- Checkout
- Order Placement
- My Orders
- Order Details
- Order Status
- Customer Profile
- Responsive Design
- REST API Integration
- Local Storage Based Cart & Order Management

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

### Backend

- Python
- FastAPI
- REST API
